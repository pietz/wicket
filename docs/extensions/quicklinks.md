# Quicklinks

Quicklinks lists the bookmarks and site searches saved in Settings ▸ Extensions ▸ Quicklinks. The lists live under `extensions.links-search` in `config.json`.

Type a saved title or keyword at the root, or type `links` to browse and filter your list. For a search link, type the keyword and query together, or select the link and enter a query when prompted. A bookmark hotkey opens the link directly. A search hotkey opens at the query prompt.

The [Quicklinks recipe](../../Sources/WicketApp/Resources/extension-contract.md#quicklinks) shows the file format and a hotkey binding.
