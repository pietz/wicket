# Caffeinate

Type `caff 2` and press Return to keep the Mac and its display awake for two hours. Type `caff`, then Tab to fill hours, minutes and seconds. With no duration, or a duration of zero, the Mac stays awake until you turn it off; a fraction of a second counts as one second. Running Caffeinate again replaces the current timer. Starting one confirms with **Awake until 17:30**, which Return leaves alone, and a separate **Turn Off** row, so pressing Return twice does not undo `caff 2`.

Inside Caffeinate, hours take the main field and Tab reaches minutes and seconds. The list leads with what you typed, **Keep Awake for 2 h 30 min** until a local time, or a hint for anything that is not a duration, and shows the current state, **Awake until 17:30** with the time left. Return on the state row runs **Turn Off**. Only with nothing typed does the state come first. Hours accept decimals with either mark (`1.5`, `1,5`). Other text shows a hint row.

Caffeinate runs `/usr/bin/caffeinate -d -i [-t seconds]` in its own session, so the timer outlives the request, the panel and Wicket itself. It records the process ID, kernel start time and deadline in `WICKET_DATA_DIR` and stops only that process. Submitted requests hold a lock there from reading the record to replacing it, so the panel and a headless run at once leave one recorded timer. `caffeinate -t` counts uptime, which pauses while the Mac sleeps, so the record keeps the deadline in uptime and each request shows it as a local time; a forced sleep moves the finish time later. When the timer ends, its row disappears on the next request; an open panel keeps what it last showed.

Hours are a text field so the keyword's argument fills them, because only a text field takes one. Minutes and seconds are number fields. Without a `match` pattern, the root row stays the plain command, and typing starts no process until you open Caffeinate.

For headless use, run `Wicket --extension caffeinate --submitted --fields '{"hours":"2"}'` to start a timer. Use `--submitted --action start` with no fields to keep the Mac awake until you turn it off, and `--submitted --action stop` to turn it off. Without `--submitted`, Caffeinate only reports the state.
