# Gallery

One of each screen Wicket draws, reached from one command, Gallery (`gallery`): an answer, a composed list (summary, facts and sections), a long summary that Read Summary opens whole, file rows (with one missing on purpose), link rows, and a page with its metadata under the text and one with it beside. Each screen is a fixed file in `screens/`, named after its hidden command, so it doubles as an example of every field the wire format has.
The file rows name paths every Mac has (Safari, Finder, `~/Desktop`, `~/Downloads`) and one that never exists.
`wicket check .` replays `session.jsonl`, which runs every screen and an unknown command.
